## ✨ About the Project

**Karoma** is a modern specialty coffee website designed to blend elegant UI/UX with practical café interactions. From browsing handcrafted drinks to personalizing an order and exploring reservations, the project focuses on a smooth and inviting customer experience.

> **Note:** This is a frontend-focused portfolio project. Ordering, tracking, and reservation flows are interactive demonstrations; they are not connected to live payment, delivery, or reservation services.

## 🚀 Features

- 🎨 **Cinematic Hero** — warm coffee imagery, smooth animations, and clear calls to action.
- 📱 **Responsive Design** — layouts adapted for phones, tablets, laptops, and desktop screens.
- ☕ **Interactive Menu** — browse drinks and pastries with categories, search, and dietary filters.
- ⚙️ **Coffee Customization** — choose available sizes, milk, temperature, sweetness, and extras.
- 🛒 **Shopping Cart** — add items, change quantities, and view updated totals.
- 📦 **Order Tracking UI** — explore an interactive order-status experience.
- 📅 **Reservations UI** — interact with café table and coffee tasting booking forms.
- 📍 **Kandy Location** — embedded Google Maps demo location, opening hours, and directions.
- ⭐ **Customer Stories** — reviews and café brand storytelling.
- ♨️ **Animated Loader** — coffee-cup auto-fill animation on initial load.

## 💻 Getting Started

### Prerequisites

- Node.js and npm installed

### Installation

```bash
# Clone the repository
git clone https://github.com/sana1211/karoma-coffee.git

# Open the project folder
cd karoma-coffee

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL shown in your terminal (the project is configured to use `http://localhost:3000` by default).

### Build for Production

```bash
npm run build
npm run preview
```

## 🌐 Deployment

Designed for static frontend deployment on **GitHub Pages**. For a repository called `karoma-coffee`, configure Vite with `base: '/karoma-coffee/'` before publishing to that path.

**Planned live URL:** https://sana1211.github.io/karoma-coffee/

> The live link will work after GitHub Pages deployment is completed. Backend-dependent features would require separate hosting and integrations.
